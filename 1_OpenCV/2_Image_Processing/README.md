
# Image Processing

This folder contains image processing techniques implemented using OpenCV.

## Topics Covered

### Thresholding

Thresholding converts a grayscale image into different intensity regions based on a threshold value.

Topics covered:

- Binary Thresholding
- Binary Inverse Thresholding
- Truncation Thresholding

## Basic Thresholding Rule

For binary thresholding:

```text
Pixel <= threshold → 0 (Black)
Pixel > threshold  → 255 (White)
```
